iPhone or iPad

  1. Download the certificate in Safari. Open Settings → Profile Downloaded (or General → VPN & Device Management), select the companion certificate and install it.
  2. Open Settings → General → About → Certificate Trust Settings. Enable full trust for Local Companion Home CA.

Android

Download the certificate, then search Settings for Install a certificate. Choose CA certificate and select the downloaded file. Menu names vary by manufacturer. Open the companion in Chrome after installing.

Windows

Open the downloaded certificate → Install Certificate → Current User → Place all certificates in the following store → Trusted Root Certification Authorities. Finish the installation and restart your browser.

Mac

Open the certificate in Keychain Access and add it to your login keychain. Open Local Companion Home CA, expand Trust and select Always Trust for SSL. Close the window and confirm the change.

Open your companion →

Allow microphone and camera when you click Start live. Use headphones for your first conversation. Only one live conversation can run at a time.
