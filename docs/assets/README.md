# Project artwork

`banner.png` and `logo.png` were generated with the built-in image-generation tool for this repository. They contain no personal photographs or runtime data. Application screenshots are actual browser captures with synthetic content.

## Banner prompt

Create a polished wide GitHub README banner for an experimental open-source project. Landscape 3:1 composition, ideally 1800x600. Restrained technical editorial design on an even near-black charcoal background (#17181b), silver and white typography with a single very restrained desaturated blue accent. On the left, large crisp sans-serif title exactly: 'Local Omni Agent'. Beneath it smaller exact subtitle: 'Real-time voice and vision. Fully local inference.' Under that, a simple small text line exactly: 'LFM3-Omni / llama.cpp / Pipecat'. On the right, an elegant sparse abstract technical composition of two open rectangular camera frames and a few precise audio waveform bars converging on a small central frame, thin silver strokes. This is a brand graphic, not a screenshot and not a fake interface. Generous spacing, confident type hierarchy, beautifully aligned. No logos from other companies, no face, robot, brain, neon, green, purple, glow, gradients, floating pills, badges, 3D, particles, rounded bento cards, personal names, network addresses, URLs or fabricated stats. No extra text. Keep all text comfortably inside 10 percent safe margins.

## Logo prompt

A clean final software logo, square 1024x1024. Uniform solid charcoal background #17181b. Centered flat white geometric symbol: two offset open square framing brackets surrounding five short vertical audio bars. Just these simple shapes. The icon occupies the central 50% of the canvas with generous margins. Flat solid near-white shapes with absolutely clean edges and consistent stroke weights. No texture, no distress, no grunge, no flecks, no gradients, no shadows, no glow, no 3D, no silver bevel, no letters, no text, no border around image. Precise, understated, professional, readable at favicon size.
